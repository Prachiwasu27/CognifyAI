# CognifyAI – Intelligent Learning Platform

CognifyAI is an AI-powered academic assistant designed to transform traditional studying into a smarter, faster, and more interactive experience. The platform leverages a Large Language Model (LLM) through OpenRouter API to generate structured academic content dynamically.

---

## 🚀 Features

- 🧠 Intelligent Topic Explanation  
- ✂ Smart Summarization  
- ❓ Automated Quiz Generation  
- 🗂 Interactive 3D Flashcards  
- 🎯 Dynamic Mode-Based UI Rendering  
- 🔐 Secure API Integration using Environment Variables  

---

## 🏗 System Architecture

CognifyAI follows a Client-Server Architecture:

User → Frontend (HTML, CSS, JS) → Backend (Node.js, Express) → OpenRouter API → LLM → Structured Response → Frontend Display

---
